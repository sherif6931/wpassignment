HTML & CSS Basics

A beginner-friendly course covering essential web foundations

Course Overview

Learn the fundamentals of web development with HTML5 and CSS3. Build responsive websites from scratch.

What You'll Learn

  1. HTML5 semantic structure
  2. CSS styling and layouts
  3. Responsive design principles
  4. Basic web accessibility
  5. Browser developer tools
  6. Simple form creation

Prerequisites

  • Basic computer literacy
  • Text editor (VS Code recommended)
  • Modern web browser

Level: Beginner

Duration: 8 hours

Time Commitment: 2-3 hours per week

Syllabus

Module 1: HTML Fundamentals

Week 1: HTML Structure

Basic tags, headings, paragraphs, links, images

Week 2: Advanced HTML

Lists, tables, forms, semantic elements

Module 2: CSS Styling

Week 3: CSS Basics

Selectors, colors, typography, box model

Week 4: Layout & Responsive

Flexbox, Grid, media queries

Data Analysis with Python

Master data cleaning, visualization, and modeling

Course Overview

Learn data manipulation, analysis, and visualization using Python libraries.

What You'll Learn

  1. Pandas for data manipulation
  2. NumPy for numerical computing
  3. Matplotlib & Seaborn for visualization
  4. Data cleaning techniques
  5. Basic statistical analysis
  6. Jupyter Notebook workflow

Prerequisites

  • Basic Python knowledge
  • Understanding of statistics
  • Jupyter Notebook installed

Level: Intermediate

Duration: 20 hours

Time Commitment: 4-5 hours per week

Syllabus

Module 1: Python for Data

Week 1: Python Review

Libraries, data structures, functions

Week 2: NumPy Basics

Arrays, operations, indexing

Module 2: Data Analysis

Week 3: Pandas

DataFrames, cleaning, manipulation

Week 4: Visualization

Matplotlib, Seaborn, plot creation
