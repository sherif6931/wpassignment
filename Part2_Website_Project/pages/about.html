The Course’s Mission.

Introduce students to the principles of modern web appliaction development; covering the entire lifecycle from building the appliaction, to design and implementation, to server and database integration. Students, by the end of this course, will have built and deployed a full-stack web appliaction to the cloud, gaining both practical and real-world project experience.

Course Objectives

  1. Design and develop reponsive, and semantically structured modern websites.
  2. Implement interactive webpages using modern JavaScript (ES6+) and learn Document Object Model (DOM) Manipulation.
  3. Build front-end appliactions using React.js with components, state management, and client-side routing.
  4. Learn to use modern DevOps and Version Control practices.

Topics Covered

  • Design and development of responsibe websites using HTML5, CSS3 (Flexbox, Grid).
  • Implementing interactivity with JavaScript.
  • Learning version control practices in Git.
  • Building front-end applications using React and JSX.
